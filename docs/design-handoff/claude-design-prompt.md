# Claude Design 用プロンプト(これを全文コピーして貼り付け)

---

あなたにはWebアプリ「Lake Sonare」の楽曲選択画面のアートディレクションを手伝ってもらいます。

## アプリの概要
- マジカルミライ2026 プログラミングコンテスト応募作品(テーマ:Lake Sonare)
- 6つの楽曲をクリアするたびに、選択画面の世界が水の循環として進化する:
  晴れ → 雲 → 雨 → 水たまり → 小川 → 川 → 湖(夏・ひまわりの湖畔)
- 実装はThree.jsのプロシージャル生成3D(ローポリスタイル)。添付した7枚のスクリーンショットが現在の実装です

## 重要な制約(コンテスト規約のため厳守)
1. あなたの成果物は「開発の参考資料」としてのみ使う。画像やHTMLをアプリに直接組み込むことはない
2. 公式イラスト・公式ロゴ・キャラクター画像(初音ミク等の姿)はデザインに含めないこと
3. 歌詞のテキストをデザイン内に書かないこと(歌詞が入る場所は「歌詞サンプル」などのダミー文字で示す)
4. 提案はすべて「コードで再現可能な形」(色コード、形状の説明、レイアウト座標、アニメーションの言葉による説明)で出力すること

## やってほしいこと
添付の各フェーズ画像について、ローポリの世界観を保ったまま品質を引き上げるリデザイン案を出してください。各フェーズにつき:
- 改善後のビジュアルカンプ(キャンバスに描画)
- 変更点のリスト(色は16進コード、追加オブジェクトは形状と配置の説明)
- 動きの提案(何がどう動くか、言葉で)

## 各フェーズの意図(参考)
- phase0 晴れ: 陽光で水が蒸発し旅が始まる草原。明るく開放的に
- phase1 雲: 上った水蒸気が集まる高空。雲の量感と高度感
- phase2 雨: 風に流される雨。しっとりした情感
- phase3 水たまり: 雨上がり。空を映す水面と雲間の光
- phase4 小川: 木立を縫う流れ。澄んだ朝
- phase5 川: 森に挟まれた大河。力強さ
- phase6 湖: 終着点。夏の青空、入道雲、富士、湖畔のひまわり群生

まず phase6(湖)から始めてください。
