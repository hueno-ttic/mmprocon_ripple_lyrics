# Visual Review Checklist

各サイクルで実ブラウザ上で以下を必ず確認すること。

- [ ] 湖面UIが表示される
- [ ] 6曲の波紋が表示される
- [ ] 「世界最後の音楽隊」を選択できる
- [ ] TextAliveの曲読み込みが開始される
- [ ] ローディング表示が破綻していない
- [ ] 曲シーンに遷移する
- [ ] 宇宙空間が表示される
- [ ] 歌詞が見える
- [ ] 歌詞が主役として読める
- [ ] 星フィールドが重すぎない
- [ ] カラーピッカーが表示される
- [ ] 色選択が画面演出に反映される
- [ ] ドローUIが表示される
- [ ] 描いた形がシーン内に反映される
- [ ] Escapeで湖面に戻れる
- [ ] Spaceで再生/一時停止できる
- [ ] スマホ幅でもUIが破綻していない
