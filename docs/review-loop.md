# Review Loop Flow

## 概要
このドキュメントは、マジカルミライ2026プログラミングコンテスト向けアプリ「Ripple Lyrics - 水の循環 -」のマルチエージェント改善ループの全体フローを定義します。
最大3サイクルの反復改善を通じて、品質と安全性を担保しながら演出を強化します。

## フロー
1. **起動確認**: npm install/build/dev を実行し、ブラウザでアプリを開く。
2. **実ブラウザでの視覚確認**: スクリーンショットや動画を保存し、見た目と動作を確認する。
3. **マルチエージェント評価**: Visual, Sync, UX, Performance, QAの5つのエージェント視点で課題を評価する。
4. **改善案の統合**: Manager Agentが課題をHigh/Medium/Lowに分類する。
5. **実装**: 分類された課題をコードに反映する。
6. **再ビルド・再確認**: buildが通るか確認し、次のサイクルへ進むか判断する。
