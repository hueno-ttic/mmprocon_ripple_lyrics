# CHANGELOG - アフター・ザ・カーテン (SongAfter)

本ファイルでは、楽曲『アフター・ザ・カーテン』（`song-after.js`）専用の演出強化、バグ修正、および機能拡張の歴史を記録・管理します。

---

## 📅 2026-06-18: [Red Curtain & Press-to-Light] 赤い緞帳の降下演出＋スポットライト挙動の刷新

### 変更内容
* **赤い緞帳（ミク背後の3D背景幕）の追加**:
  * Three.js の平面メッシュ（z=-5、ミクより背景側）に、Canvas 生成のベロア質感テクスチャ（縦ひだ＋上下の陰影＋裾の金モール）を貼って表現（`createCurtainTexture`）。
  * **開演**: 再生開始（`eventBus 'play'` → `dropCurtain()`）で、フレーム上方（Y=30）からミク背後の定位置（Y=2）へ**上から降りてくる**。
  * **そのまま留まる**: 終演で閉じる演出は持たない（閉幕機能なし）。サビ時は緞帳は動かず、上方の夜空（星）だけが瞬く。
  * ※当初は CSS の左右開閉幕として実装したが、「ミク背後で上から降りる縦型の緞帳／閉幕なし」へ方針変更し作り替え。
* **スポットライトを「押している間だけ」点灯に変更**:
  * `isPointerDown` を導入し、`spotOn`（0↔1 の補間）で点灯/消灯をなめらかに制御。押下中のみ `mouseLight` が照射。
  * 追尾は押下中の `pointermove` のみ反映（離すと消灯）。`pointerup`/`pointercancel` は `window` で捕捉し、`setPointerCapture` でドラッグを安定化。
  * 歌詞・床のバラの「照らし切り」判定も `spotOn > 0.4` を条件に追加。
* **スポット以外を薄暗く**: `ambientLight` 0.5 / `pointLight` 8 / 自動スイープ `spotLight` 22 へ減光。
* **歌詞の端切れ修正**: `createTextTexture` がテキスト幅を計測し、キャンバス幅に収まるようフォントを自動縮小（72→最小34px）。
* **フレーズの文法的分割**: `splitPhraseText` を追加。長いフレーズ（>14字）のみ、助詞・句読点など語を割らない境界で 2〜3 分割（過分割しない）。

### 検証
* ビルド成功。実機（dev/TextAlive）で自動再生→開幕、押下時のみ点灯（spotOn 0→0.99→0）、追尾、薄暗さ、長尺歌詞の全表示を確認。分割は Node で決定的に検証。

### 既知の残課題
* TextAlive の `findPhrase` 自体が短いフレーズを語中で区切る場合があり（例「ひと」/「つひとつ」）、本分割は長文のみ対象のため未補正（連続フレーズの再結合は未実装）。

## 📅 2026-05-26: [Vocal Pulse & Spotlight Sync] 歌唱パルスおよびスポットライト透過同期の実装

### 変更内容
* **歌唱ビートに同期した「発話連動パルス」演出の実装**:
  * スポットライトに照らされる初音ミクの歌唱に合わせて、対応する3D歌詞スプライトが **1.25倍に脈動拡大し、マテリアルの Emissive（自発光）がエメラルド色に強くブースト発光** する演出を実装。
  * 歌詞の出現フェードイン時間を **150ms** に、フェードアウトを **200ms** に短縮し、感覚的な描画ラグを根絶。
