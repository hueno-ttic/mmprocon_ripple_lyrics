## 📅 2026-06-10: [Feature] 3D VRMモデル (Hatsune Miku) の導入と正面向き補正・インタラクティブ歌詞タップ・視線追従演出の実装

### 変更内容
* **3Dアバターのロードと配置**:
  - `public/assets/models/miku.vrm` (ユーザー提供のVRMモデル) を `@pixiv/three-vrm` および `GLTFLoader` を用いて非同期ロード。
  - カメラの手前（Z=2.5、Y=-1.8、X=0、向きはカメラ正対）に配置し、無重力空間に漂うような自然な脱力状態ポーズ (`setupRelaxedPose`) を初期設定。
* **正面向きの完全維持と揺らぎの調整**:
  - 体が左右に向きを変えてしまわないよう、Miku の `rotation.y` を `baseMikuRotY`（カメラ正対）に完全固定。自然な浮遊感（Y軸上下・X軸左右揺らぎ、Z軸の極小のロール傾き）のみに絞り、正面向きを安定してキープ。
* **歌詞タップに連動したインタラクティブ腕伸ばしアニメーション**:
  - ユーザーが画面上の歌詞スプライトをクリックした際、カメラからその歌詞に向けた視線ベクトル（Line of Sight）を計算し、Miku の腕が届く距離（Z=3.8付近）に投影した reachable 座標 `projectedTarget` を算出。
  - 歌詞のX座標の正負によって左手または右手を選択し、肩（`leftUpperArm` / `rightUpperArm`）および肘（`leftLowerArm` / `rightLowerArm`）をクォータニオン球面線形補間（slerp）でターゲットに向けてまっすぐ伸ばす腕伸ばしアクション（全体時間0.7s、ピーク時間0.3s）を実装。
* **生き生きとした視線追従 (LookAt)**:
  - 通常時は首ボーン（`neck`）が常にカメラ位置を見つめてユーザーと目線を合わせ（Eye Contact）、歌詞タップ中は首ボーンが滑らかに `projectedTarget`（被タップ歌詞）の方向へ回転して見つめ、タップ完了後は再び自然にカメラへ目線を戻す LookAt 制御メソッド（`lookAtTarget`）を実装。
* **歌詞のフリーズ・遅延昇華・接触火花エフェクト (Touch Sparkles)**:
  - ユーザーが歌詞をクリックした際、即座にオーブ化するのではなく、その場で歌詞の上昇・横揺れをフリーズさせて一時停止。
  - Miku の手が歌詞の投影位置に接触する瞬間（アニメーション開始から0.3秒のピーク時）に、歌詞がカラーオーブへ変化（昇華）し、同時に加算合成のぼかし発光テクスチャを用いた衝撃スパークル（40個の軽量粒子バースト、`spawnTapSparkles`）を発生させ、触って弾けさせた物理的質感を演出。
* **宇宙空間での浮遊・呼吸・拍動アニメーション**:
  - TextAlive再生位置（時間）を基に、Y軸（ゆったりとした昇降）・X軸（左右の揺れ）およびY/Z回転にサイン波を用いたスムーズな浮遊物理を適用。
  - 両肩・両肘ボーンに微弱な逆位相のZ/Y軸サイン回転を加えることで、無重力空間でゆったりと呼吸・漂っているようなリアリティのあるボーンアニメーションを表現。
  - 楽曲のビートタイミングに同期して、モデル全体がわずかに拍動（スケールが3%程度パルス拡大）するリズム連動演出を追加。
* **揺れもの物理演算（SpringBone）の同期**:
  - ツインテールや服の接合関節が、モデルの慣性移動や風・重力変化に反応して自然にたなびくよう、`performance.now()` による実時間デルタ秒（`deltaTime`）を用いた `vrm.update(deltaTime)` 物理更新ループを毎フレーム実行。
* **歌声（Vocal）に連動したリアルタイム・リップシンク（口パク）**:
  - TextAliveから取得する現在発話中の文字（`currentWord.text`）の頭文字から日本語母音（あ・い・う・え・お）を瞬時に判別する日本語母音正規表現マッパーを実装。
  - VRMの `ExpressionManager` を通じて、母音ブレンドシェイプ（`aa`, `ih`, `uu`, `ee`, `oo`）をターゲット値 `0.85` に向け線形補間（イージング）させ、滑らかかつ正確に歌声に連動して口が開閉する高精度なリップシンクを実現。ボーカル無音時は口を閉じる。
* **立体感と質感を与える照明（Lighting）の追加**:
  - アバターモデルが宇宙の暗闇に埋もれないよう、全体を淡い青紫で照らす環境光（`AmbientLight` / 強度1.8）と、ディテール・陰影の立体感を引き出す平行光源（`DirectionalLight` / 強度2.5）をシーンに追加。
* **徹底的なメモリリーク防止（dispose）処理**:
  - 楽曲切り替え時や湖面への帰還時 (`destroy` 呼び出し時) に、`this.currentVRM` をシーンから除外。
  - ロードしたアバターの全メッシュを階層走査（`traverse`）し、すべてのジオメトリ（`geometry`）およびマテリアル・テクスチャ（`material.map` / `material`）を個別に `dispose()` してGPUメモリから確実に完全解放する `disposeVRM()` を実装。

## 📅 2026-06-06: [Focus Word Visual Polish & Bottom Main Lyric UI] 歌詞カテゴリ自動分類・固有フォント演出 ＆ 画面中央下Main Lyric常時表示の実装

### 変更内容
* **画面中央下のMain Lyric常時表示**:

  - 明朝体フォント、黒色アウトライン・ドロップシャドウ、半透明背景、バックドロップぼかし（`backdrop-filter: blur(8px)`）を適用し、星空の背景に埋もれない高い視認性を確保。
  - モバイル/スマホ向けレスポンシブデザイン（明朝体フォントサイズ縮小、下部余白調整）を実装。
  - `destroy()` 時の確実なDOM/Style要素クリーンアップを実装し、メモリリークを排除。
* **Focus Word の自動カテゴリ分類 (`getWordCategory`)**:
  - テキスト中の文字パターンから、指定された9つの感情/意味カテゴリ（`sky_color`, `light`, `machine`, `music_march`, `music`, `voice_echo`, `future_memory`, `sadness`, `default`）に動的に分類する仕組みを導入。
* **カテゴリ固有のビジュアル表現（Canvas 2Dテクスチャ & 3Dエフェクト）**:
  - **`machine`**: Gothicフォント、赤とシアンの色収差（Chromatic Aberration）を再現、`update`時の微細なランダムGlitch座標オフセットを適用。
  - **`music` / `music_march`**: 五線譜（5本の水平ライン）を背景に描画。`music_march` はビート（`beat.startTime`, `beat.duration`）に同期した縦方向の正弦波バウンド、および進行方向（`marchDirection`）への横スライド移動。
  - **`voice_echo`**: 音波サイン波を描画、文字の残像（3重テキスト）描画、背後に淡く発光する光暈（`glowTexture`）を子スプライトとして追加。
  - **`light`**: 背後に発光する光暈（`glowTexture`）を子スプライトとして追加。
  - **`future_memory`**: 星座の星と結ぶ直線パターンを描画、表示寿命を長く設定 (`duration + 2500`)。
  - **`sadness`**: 薄い半透明（opacity: 0.65）の重みのある明朝体、微細なシェイク（震え）の適用。
* **表示制限とリソース解放の徹底**:
  - 画面内の同時歌詞スプライト表示数を最大3個に制限。
  - `disposeSprite` ヘルパーを新設し、スプライト削除・昇華（オーブ化）・`destroy()` 時に、マテリアル・テクスチャおよび子スプライト（光暈など）を漏れなく確実に破棄しメモリリークを防ぐ。

## 📅 2026-06-06: [Bug Fix & Visual Polish] サビ花火打ち上げオーブの重複・残存バグの修正 ＆ 背景色の明滅抑制 ＆ オーブ発光エフェクト ＆ 花火2倍スケールアップ

### 変更内容
* **サビ花火打ち上げオーブの重複・無限スポーンバグの修正**:
  - **原因**: サビ（Climax）中に時系列で打ち上げられる `this.climaxOrbs` のオーブが、目的地（宇宙の奥、`t >= 1.0`）に到達して大爆発した際、シーンやトレイルからは削除されていましたが、管理配列 `this.climaxOrbs` 自体からは削除されていませんでした。そのため、一度目的地に到達したオーブが毎フレーム爆発判定をループ通過し続け、無駄な `scene.remove`、素材の多重 `dispose`、および毎フレーム新しい花火パーティクルが無限に生成・残存する現象が発生していました。
  - **対応**: 打ち上げ処理を `this.climaxOrbs.forEach` から `this.climaxOrbs = this.climaxOrbs.filter(...)` によるフィルタリングループに改修。目的地に到達して大爆発を終えたオーブは、配列から確実に即時除外されるように根本修正しました。これにより残骸の無限生成がなくなり、花火がパッと咲いて美しく儚く消えていく本来のライフサイクルが実現されました。
* **背景とフォグの過度なフラッシュ・色の明滅の抑制**:
  - **原因**: 各花火の爆発時に、その花火の色を `this.scene.background` や `this.scene.fog.color` にコピーして環境光をシミュレートしていましたが、複数の花火が短時間で連鎖爆発するサビにおいて、背景の空全体の色がチカチカと激しく変わりすぎ、情緒を損ねる原因になっていました。
  - **対応**: 花火爆発時の背景色・フォグカラーの上書き処理（および星々 `this.starMaterial.color` の上書き処理）を無効化し、常に深宇宙の静かで安定したダークブルー（`0x050510`）を維持するように修正しました。これにより、視覚的に眩しすぎず、花火自体の粒子カラーが美しく映える情緒ある演出になりました。
* **オーブのぼかし発光エフェクト（Glow Halo）の追加**:
  - 蓄積される色彩オーブに、中心が白く周囲が固有色に滲む「ぼかし発光テクスチャ（Canvas 2Dで動的に生成）」を用いた `Sprite` 粒子を「加算合成（`THREE.AdditiveBlending`）」で重ね合わせました。これにより、単なる平坦な球体から、自発光して優しくきらきらと輝く幻想的な光の精霊へとビジュアルを劇的にアップデートしました。
* **花火の2倍サイズへの超スケールアップ ＆ 火花の加算発光化**:
  - サビで打ち上がる花火を、前回の調整値から**さらに2倍大きく（直径比）**打ち上がるように拡張しました。
  - 爆発速度（拡散スピード）を `0.45〜0.95` から `0.95〜1.95` へ倍増させ、爆発する最大半径を2倍以上に拡張。
  - 火花粒子が広がりきった後も美しく消え入るよう、寿命（`maxLife`）を `1400ms` から `1800ms` へ延長しました。
  - 粒子の数も `180個` へ引き上げ、さらに火花自体にも加算合成のぼかし発光テクスチャを割り当てることで、火花同士が重なった部分が白く強く輝く、極めてリアルで豪華な花火の質感を表現しました。

  * 以前の仕様でサビ終了後に新しく生まれたオーブが静止したり、正常に生成・螺旋周回しなくなっていたバグを解消。
  * 蓄積用配列（`resonateOrbs`）のアニメーション更新を、サビ中・サビ後にかかわらず常時受けられるクリーンな物理ループにリファクタリング。これにより、サビが終わった後も再び歌詞をタップしてオーブを溜め直せる完璧なライフサイクルが保証されました。
